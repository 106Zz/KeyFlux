# KeyFlux v0.1.0

KeyFlux 首个公开版本，为 macOS 提供原生菜单栏中英文与大写切换。

## 功能

- 单按 Shift 切换系统 ABC 与 Apple 拼音，保留 Shift 组合输入。
- 短按中/英键进入大写 ABC，再按一次回到小写 ABC。
- 大写状态下单按 Shift 关闭大写，下一次 Shift 切入拼音。
- 菜单栏启用、暂停、权限检查与退出。
- 可选登录自启及监听故障恢复。
- 配套 App、DMG 文件与挂载卷图标。

## 下载与安装

下载 Assets 中的 **KeyFlux-0.1.0-arm64.dmg**，将 KeyFlux.app 拖入 Applications，然后从“应用程序”打开。提供同名 `.sha256` 文件用于校验。

- 平台：Apple Silicon Mac（arm64）。
- 构建最低系统版本：macOS 11.0。
- 日常使用验证环境：macOS 27.0.1 / Apple Silicon。

首次使用需要辅助功能及输入监控权限，并在系统设置中启用 ABC / Apple 拼音、关闭系统使用中/英键切换输入法的选项。完整步骤见 [安装说明](https://github.com/106Zz/KeyFlux#安装)。

本版采用 ad-hoc 签名，未经 Apple 公证。首次打开若被系统拦截，请确认下载来源后参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 已知兼容性问题

外接键盘可能出现低频短暂失效后恢复的情况；持续异常时可暂停后重新启用。安全输入期间会放行相关操作，远程桌面、游戏和特殊输入框的行为可能不同。

反馈请使用 [GitHub Issues](https://github.com/106Zz/KeyFlux/issues)。
