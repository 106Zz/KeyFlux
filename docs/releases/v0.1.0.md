# KeyFlux v0.1.0

首个公开版本：用于 macOS 的原生菜单栏键盘工具，使用 Rust 编写。

## 下载与安装

- **Apple Silicon（arm64）**：下载本页 Assets 中的 `KeyFlux-0.1.0-arm64.dmg`。
- 下载同名 `.sha256` 文件可核对安装包完整性。
- 将 `KeyFlux.app` 拖入 Applications，从“应用程序”打开。
- 构建最低系统版本为 macOS 11.0；日常验证环境为 macOS 27.0.1 / Apple Silicon，其他系统版本尚未逐一验证。
- 当前没有 Intel 或 Universal 安装包。

**本版采用 ad-hoc 签名，尚未经过 Apple 公证。** 首次打开可能被 macOS 拦截；确认来源及校验值后，请参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 处理本次打开提示。

完整安装、权限和使用说明见 [README](https://github.com/106Zz/KeyFlux#安装与首次设置)。

## 本版功能

- 单按 Shift 在系统 ABC 与 Apple 拼音之间切换。
- 短按中/英键开关大写；关闭大写后留在小写 ABC。
- 大写状态单按 Shift 回到小写 ABC，下一次 Shift 再切入拼音。
- 原生 ⇧ 菜单栏，可暂停、重新启用、检查权限和退出。
- 可选登录自启，默认关闭。
- 可恢复监听错误的自动重建，以及独立的性能采样工具。
- 新增统一的 App、DMG 文件和挂载卷图标。

使用前请启用 ABC / Apple 拼音，授予 KeyFlux 辅助功能及输入监控权限，并关闭系统使用中/英键切换输入法的选项。

## 已知限制

- 外接键盘日常使用中仍可能低频短暂失效、随后恢复，原因尚未完全定位。
- 安全输入期间会放行相关操作；远程桌面、游戏和特殊输入框尚未全面验证。
- 一次此前日常采样的预热后 Footprint 平均约 21.18 MB、采样峰值约 23.45 MB；包含睡眠或采样空档，新图标包尚未重新进行资源采样，不承诺 15 MB 指标。
- 本次发布完成 Release 编译、App 签名校验及 DMG 数据校验；没有重新运行测试或启动 App。互联网下载后的权限、键盘和登录自启仍需在自己的设备上确认。

反馈问题请使用 [Issues](https://github.com/106Zz/KeyFlux/issues)，提供系统版本、键盘及连接方式、应用名称、发生时间和失效按键，不要上传输入内容或敏感信息。
